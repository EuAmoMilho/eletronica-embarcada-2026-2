# Test Point 1

Microcontrolador: PIC16F886

## Objetivo

Criar um software que realize a operação de adição entre dois operandos de 8 bits, localizados como entradas nas portas B (pull-up interno ativado) e C do microcontrolador, e apresentar o resultado na saída, porta A do microcontrolador.

A presença de carry e overflow nas operações é desconsiderada.
