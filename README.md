# eletronica-embarcada-2026-2

Esse repositório contém as atividades práticas desenvolvidas na disciplina de Eletrônica Embarcada no semestre 2026.2 da Universidade de Brasília.

O material aqui desenvolvido consiste em exercícios semanais (Test Points) na pasta `test_points`, uma prova avaliativa na pasta `prova` e um projeto final `projeto_final`.
